How the value is built. Implied value = TVL × tier × growth × maturity × breadth. The tier is 0.18 at $5B TVL or more, 0.22 at $1B, 0.28 at $100M, 0.35 below it. Growth scales with the seven-day TVL change, clamped to −60%…+120%. Maturity rises with the days the protocol has run with no token, capped at three years. Breadth adds 3% per extra chain, up to five. A protocol records no token when DefiLlama carries no token id or symbol for it — that is a record, not a promise that it has none.
